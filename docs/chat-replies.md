# AI 채팅 답변 종류

AI 채팅의 AI 답은 대부분 글 한 덩어리다(`msg.text`). 이 문서는 **글 말고 다른 것이 붙는 답**을 모두 정리한다.

- 예시 계정에서 모두 볼 수 있다.
  - 모여봄의 「AI 답변 종류 모아 보기」 방에 GitHub 연결 전 모습을 뺀 전부가 있다.
  - GitHub 연결 전 모습은 슬랙봇의 「AI 답변 종류: GitHub 연결 전」 방에 있다.
  - 예시 데이터는 `prototype/js/seed-replies.js`에 있다.
- 그리는 곳은 `prototype/js/screens/chat.js`의 `msgHTML`이다. 답을 만드는 곳은 `prototype/js/chat.js`다.

## 한눈에

| 종류 | 표시 | 언제 생기나 | 사용자가 할 수 있는 것 |
|---|---|---|---|
| 카드 칩 | `msg.touch` (다른 종류와 함께 붙을 수 있다) | AI가 카드를 만들거나 고친 답 | 칩을 눌러 오른쪽에서 그 카드 펼치기 (없는 카드면 알림) |
| GitHub로 이어 주기 | `kind: 'link'` | 「깃허브에서 찾아줘」처럼 말했을 때 | 「GitHub에서 찾기」 또는 「GitHub 연결」 |
| 레포 분석 | `kind: 'github'` | GitHub에서 찾기를 시작했을 때 | 상태마다 다르다 (아래) |
| 바꾸기 전에 묻기 | `kind: 'confirm'` | 「카드 바꾸기 전에 묻기」를 켜고 AI가 카드를 바꾸려 할 때 | 반영하기, 항상 허용, 거절 |

입력 중 표시(점 세 개)와 새 채팅 안내는 대화에 남지 않아서 이 목록에 넣지 않는다.

## 1. 카드 칩 (`touch`)

`msg.touch = { card, title, created, fields }`는 이 답에서 바꾼 카드와 바뀐 칸이다. 칩은 답의 글 **위**에 붙는다. 카드 이름은 칩에만 나오고 글에서는 되풀이하지 않는다.

칩은 카드가 어디에 있든 같은 모습이다: 카드 아이콘, 카드 제목, 바뀐 칸(「상황, 행동」). 제목은 그 답을 만들 때 `touch.title`에 남겨 둔다. 카드가 휴지통에 있으면 휴지통의 제목을 쓴다.

| 누르면 | |
|---|---|
| 카드가 있음 | 오른쪽 패널에서 그 카드가 펼쳐진다 |
| 휴지통에 있음 | 「휴지통으로 옮긴 카드예요」 알림과 「휴지통 보기」 |
| 완전히 지워짐 | 「지워진 카드예요」 알림 |

레포 분석의 만든 카드 목록도 같은 규칙을 따른다.

카드 칩이 붙은 답이 처음 그려질 때 오른쪽 패널은 그 카드를 펼친다. 바뀐 칸에는 연한 형광펜이 한 번 깔렸다가 걷힌다.

## 2. GitHub로 이어 주기 (`kind: 'link'`, `link: 'github'`)

말로 GitHub 찾기를 부탁하면 붙는 단추다.

- 프로젝트에 레포를 연결했으면 「GitHub에서 찾기」 단추가 붙는다. 누르면 이 방에서 레포 분석이 시작된다.
- 연결하지 않았으면 「GitHub 연결」 단추가 붙는다. 연결한 뒤 이 방에서 레포 분석이 시작된다.

예전에 있던 `link: 'new'`(새 채팅 단추)는 대화방이 프로젝트 단위가 되면서 만들지 않아 지웠다.

## 3. 레포 분석 (`kind: 'github'`)

`msg.gh = { status, step, picked, drafts, madeIds, error }`

| 상태 | 글 | 붙는 것 |
|---|---|---|
| `connect` | 이 프로젝트에 연결한 GitHub 레포가 아직 없어요 | 「GitHub 연결」 (연결했으면 「GitHub에서 찾기」) |
| `running` | 연결한 GitHub 레포를 읽고 있어요 | 레포 이름과 단계 진행 표시. 화면을 떠나도 이어진다 |
| 멈춤 (저장된 `running`인데 지금 돌고 있지 않음) | GitHub 레포를 읽다가 멈췄어요 | 「다시 시도」 |
| `error` | 레포를 다 읽지 못했어요 | 빨간 알림에 까닭, 「다시 시도」 |
| `ready` | 커밋 N개와 PR N개를 읽고 작업을 N개 찾았어요 | 초안 목록(고르기 칸, 자세히 보기), 「모두 고르기」/「모두 해제」, 「경험 카드 N장 만들기」 |
| `empty` | 새로 카드로 만들 작업은 없어요 | 이 레포에서 만든 카드 목록(있으면) |
| `done` | 경험 카드 N장을 만들었어요 | 만든 카드 목록(카드마다 「카드 보기」, 비어 있는 칸), 남은 초안이 있으면 「남은 작업 N개 보기」 |

`ready`에서 남은 초안이 하나도 없으면 `done`으로 보인다. 그때 만든 카드가 없으면 「찾은 작업은 모두 경험 카드로 있어요」라고 쓴다.

## 4. 바꾸기 전에 묻기 (`kind: 'confirm'`)

입력창 위의 「카드 바꾸기 전에 묻기」를 켰을 때만 생긴다. AI는 바꿀 내용을 상태의 복사본에서 미리 해 본다. 그런 다음 바뀔 칸만 앞뒤로 보여 준다. 지운 글자에는 취소선이 그어지고, 더한 글자에는 형광펜이 칠해진다.

`msg.pending = { op, cardId, before, after, fields, ids, cmd, next, status }`

| `op` | 묻는 말 | 「예」 단추 |
|---|---|---|
| `create` | 새 경험 카드 「…」를 만들까요? | 만들기 |
| `update` | 「…」 카드의 결과를 이렇게 바꿀까요? | 반영하기 |
| `delete` | 「…」 카드를 휴지통으로 옮길까요? | 휴지통으로 옮기기 (빨간 단추). 바뀔 칸 상자 없이 단추만 붙고, 답한 뒤에는 아무것도 붙지 않는다 |

| `status` | 모습 |
|---|---|
| `wait` | 단추 세 개: 반영하기, 항상 허용(토글을 끈다), 거절. 오른쪽 패널 위에 「허락을 기다려요」가 보인다 |
| `ok` | 점선 테두리, 「허용했어요」 |
| `no` | 점선 테두리, 「거절했어요」. 그 말은 카드에 담지 않는다 |
| `fail` | 점선 테두리, 「반영하지 못했어요」. 기다리는 사이 카드가 바뀌었거나 휴지통에 있었다 |

허용하면 AI가 이어서 할 말(`next`)이 카드 칩과 함께 붙는다.

카드를 휴지통으로 옮긴 뒤의 답(「… 카드를 휴지통으로 옮겼어요」)은 일반 글이다. 되살리기는 휴지통에서 한다.
